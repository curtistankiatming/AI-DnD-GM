BRIARWATCH 4.1.0-alpha.3 — START HERE

Briarwatch is a story game. You create a hero, choose what they do, and the
dice decide how it goes. Two companions travel with you. This is an unfinished
public alpha; see docs/CURRENT-STATUS.md for dated evidence.

THE QUICK WAY TO PLAY (Windows, full source)
1. Install Node.js 22 or newer from nodejs.org if you do not have it.
2. Extract the source ZIP to its own new folder.
3. Double-click run-local.bat. The first run installs one small library, then
   the game opens in your browser at http://localhost:4173.
4. Press "New adventure" on the title page, give your hero a name and pick a
   class.
On other systems, run "npm install" once and then "npm start".

PLAY WITH THE CLAUDE AI GAME MASTER (optional, recommended)
With Claude on, you can type anything you want to try, Claude narrates the
story, and after the first story it can write new adventures for you. The game
still rolls the dice and tracks items, gold and experience.
1. Get an API key from console.anthropic.com, under API keys. Usage is billed
   to your Anthropic account.
2. When you create your hero, choose "Claude AI game master", paste the key
   into the box and press "Save key and test". That is all.
   (Already playing? Open Settings, then "AI settings", and use the same box.)
The key stays on this computer in a private file and is never put in a save.
Without a key the game works fully offline with its written story and choices.
A local model server can be used instead of Claude; see GAME-GUIDE.md.
EVALUATE-MODEL.bat offers a guided three-prompt test for a local model.

NO-INSTALL BROWSER EDITION
Extract briarwatch-browser-playtest.zip and open briarwatch-playtest.html.
No Node.js, account, API key or internet is needed after downloading. This
edition never calls an AI model. To build it from source, run
"npm run build:public" and open dist-public/briarwatch-playtest.html.

UPDATING FROM AN OLDER VERSION
Back up the old installation and export a JSON save before updating or changing
browsers. Do not overwrite old files or publish saves or credentials. Keep the
local server and any model private; neither is a secure public service.

WHAT IS IN THE GAME
The written campaign runs from level 1 to 10 and ends with the Oath of the
Road trial. Heroes then grow to level 100 through jobs: a 2nd job at level 20
(three branches per class), a 3rd job at 40 and a 4th job at 70, each unlocked
by a trial, with an ultimate skill at 100. After that, renown ranks continue
without end. Lantern Road is an optional journey in Briarwatch with lasting
consequences. The journal remembers confirmed facts, promises and leads. With
Claude on, the AI game master writes new adventures after the bell
investigation; you choose Normal, Hard or Heroic before each one.
